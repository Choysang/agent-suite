# daily — 待办与工作日志

Vault：`.`（vault 根目录）。待办的唯一真相源是 `50.Daily/TODO.md`。daily 是自动生成的工作日志，记录每天完成了什么、开了什么会、随手记了什么。日期以系统真实日期为准。

## 开工

1. **补完成记录**：在 `TODO.md` 里找行尾带 `✅ <日期>`、但还没写进日志的完成项，按完成日期写进当天日志的「完成」区；日志文件不存在就按下面的模板新建。
2. **建今天的日志**：`50.Daily/<YYYYMM>/<YYYY-MM-DD>.md`，已存在就跳过。
3. **填会议**：若存在 `20.Areas/会议/会议清单.md`，读取并计算；没有就跳过，不补造会议。「每周X」直接匹配星期；「双周(锚点日期)」用 (今天 - 锚点) 的天数 mod 14 == 0 判定。今天的会议写进日志的「会议」区，本周其余的只在汇报里列出。格式 `[会议名](链接) · 时间 · 会议号/密码`。
4. **扫收件箱**：`00.Inbox/` 有文件（排除 `_` 开头和 `.intake`）就报数量，提醒有空跑 `tidy`。
5. **汇报**（一屏内）：未完成待办（按 工作 / 学习 / 其他 分组）、今天和本周的会议、昨天完成几项、收件箱数量。

## 随手操作

- 「加待办 X」→ 写进 `TODO.md` 对应分组。
- 「X 完成了」→ `TODO.md` 里该项改成 `[x]`，行尾加 `✅ YYYY-MM-DD`，同时写进当天日志的「完成」区。
- 「记一下：X」→ 追加到当天日志的「记录」区，前面加 `HH:MM`。

## 日志模板

```markdown
---
type: daily
date: "YYYY-MM-DD"
---

# YYYY-MM-DD

> 自动生成的工作日志：daily 填会议与完成项，「记一下：…」追加记录。待办在 [[50.Daily/TODO|TODO 清单]]。

## 会议

## 完成

## 记录
```
