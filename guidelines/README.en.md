# Working guidelines

[Agent Suite](https://github.com/Choysang/agent-suite) · [中文](README.md) · [Download this module](https://github.com/Choysang/agent-suite/releases/latest/download/guidelines.zip)

Reusable instructions for checking assumptions, keeping solutions simple, preserving unrelated work, completing authorized tasks, and reporting verification honestly.

| Agent | Instructions | Use |
|---|---|---|
| Codex | [English](codex/AGENTS.en.md) / [Chinese](codex/AGENTS.md) | Project `AGENTS.md`, or `~/.codex/AGENTS.md` for personal defaults |
| Claude chat | [English](claude/INSTRUCTIONS.en.md) / [Chinese](claude/INSTRUCTIONS.md) | Personal preferences in Claude settings |
| Claude Code / other agents | [English](universal/AGENTS.en.md) / [Chinese](universal/AGENTS.md) | Project `CLAUDE.md` for Claude Code; the supported instruction entry for other agents |

Pick one edition. Merge with existing rules instead of overwriting them. Replace `<vault>` with your own knowledge directory if you use the knowledge module; otherwise remove those entries.
