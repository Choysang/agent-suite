# 🚀 Agent Workflow Suite (智能体全流程协同与认知系统)

> **让你的 AI 编程助手具备「统一的纪律」、「无损的接力记忆」与「可复利的第二大脑」。**  
> 本项目整合了三个核心开源理念的精华：**行动指南 (Guidelines)** + **会话接力 (Handoff)** + **第二大脑知识库 (Obsidian-Wiki-llm)**，提供了一套面向个人开发者与团队的**开箱即用 Agent 工作流分享与实战工具包**。

---

## 💡 为什么需要这一套联合体？

日常使用 AI 编程助手（如 Claude Code、Cursor、OpenAI Codex、Windsurf 等）时，所有开发者都会撞上**三大致命痛点**：

| 痛点场景 | 没有本系统时的现状 | 使用本系统后的改变 |
|---|---|---|
| **1. AI 瞎编与过度重构** | AI 喜欢凭空虚构不存在的库、擅自把好好的代码大拆大改、满嘴套话。 | **【行动指南】** 给 AI 立下铁律：独立客观、证据第一、外科手术式微创修改。 |
| **2. 上下文爆炸与换模型失忆** | 会话聊久了变卡变笨；开新窗口后 AI 彻底失忆，一切从头解释，甚至重复踩坑。 | **【会话交接手】** 一键 `/handoff` 封存快照；新窗口或新模型一秒无缝接力。 |
| **3. 踩过的坑明天接着踩** | 今天花半天调通的深坑，明天开新会话 AI 依然重蹈覆辙，经验无法沉淀。 | **【第二大脑】** 踩坑一键 `sink` 沉淀为知识卡片；下次全团队终生免疫同一个 Bug。 |


## ⚡ 三分钟快速上手 (Quickstart)

### 步骤 1：给你的 Agent 装上“行为准则”
根据你日常使用的工具，把 `templates/agents/` 里的配置文件复制到你的工作区：
- **用 Claude Code**：将 [`CLAUDE.md`](templates/agents/CLAUDE.md) 放到你的项目根目录或 `~/.claude/`；
- **用 Cursor**：将 [`.cursorrules`](templates/agents/.cursorrules) 放到项目根目录；
- **用 Codex**：将 [`CODEX.md`](templates/agents/CODEX.md) 放到项目根目录；
- **通用环境**：将 [`AGENTS.md`](templates/agents/AGENTS.md) 作为系统级 Prompt 导入。

*效果：AI 立即停止瞎编和破坏性重构，严格遵循“证据第一”与“外科手术式修改”。*

---

### 步骤 2：会话接力体验 (跨会话/跨模型不失忆)
在任意安装了 `handoff` 技能的 Agent 窗口中：
1. **封存当前状态**：
   ```text
   /handoff
   ```
   *AI 会自动提炼当前进展、已验证事实、被否决的方案，并把快照保存在仓库的 Git 引用 `refs/handoff/<编号>` 中。*
2. **在新窗口或换一个模型接手**：
   ```text
   /handoff 1
   ```
   *新 AI 秒级读取现场和代码差异，无需任何背景解释，直接自动开始写下一步代码！*

---

### 步骤 3：多通道知识入库 (把外部智慧变成本地资产)
你在网上看到好项目、读到好文章，或者遇到踩坑：
- **存一个 GitHub 仓库**：
  > “帮我入库这个项目：https://github.com/feitangyuan/onetake”
- **处理浏览器网页剪藏**：
  > “处理 Clippings/ 里的剪藏文章”
- **聊天框贴来一段经验**：
  > “记一下这段踩坑做法：[粘贴文本]”
- **刚刚搞定了一个顽固 Bug**：
  > “沉淀一下刚才的踩坑经验” (触发 `sink`)

*底层引擎会自动查重、评定采纳等级、按照契约生成卡片，并运行 `kb build` 重新编译路由。*

---

### 步骤 4：每日开发飞轮 (越用越聪明的正向循环)
每天开工时对 AI 说一句：
> “开工，今天有什么待办？”

AI 会自动读取待办事项，同时常驻载入最新的知识库路由表。昨天刚沉淀的经验，今天开工立刻就能被 AI 检索命中！
